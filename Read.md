# CoffeeCat – Coffee Shop Website

A modern, stylish, and responsive website for a coffee shop called **CoffeeCat**, designed to showcase services, menu, special offers, and allow online reservations.

## 🚀 Features

- Beautiful and responsive layout
- Clear service sections: About, Vision, Services, and Pricing
- Sunday special offer section with 50% discount
- Online reservation form
- Footer with contact info, social media, and open hours
- Smooth scrolling and interactive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts / Custom Fonts
- Font Awesome Icons

## 📸 Sections Overview

- **Hero Section**: Eye-catching intro with coffee cup and slogan
- **About Us**: Short story and mission/vision
- **Our Services**: What makes us special (delivery, quality beans, online booking)
- **Special Offer**: Sunday discount banner
- **Menu & Pricing**: Coffee types with pricing
- **Reservation Form**: Book your table form with confirmation
- **Footer**: Contact info, social media, opening hours, newsletter signup

## 📦 Installation

You can open the project by simply opening `index.html` in a browser:

```bash
git clone https://github.com/yourusername/coffeecat-website.git
cd coffeecat-website
open index.html
```
